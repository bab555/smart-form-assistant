# 智能表单助手 - 前端开发工作流

## 📋 项目概览

本项目是一个基于 **React 18 + TypeScript + Vite** 的现代化前端应用，实现了 AI 驱动的多模态智能表单填写系统。

## 🎯 核心功能实现指南

### 功能 1：图片上传与识别

**流程**：
1. 用户点击上传按钮 → `FileUpload.tsx`
2. 选择图片文件 → `useFileUpload` Hook 验证
3. 上传到后端 → `api.recognizeImage()`
4. 后端返回识别结果 → 自动转换为 `camelCase`
5. 添加到表格 → `useFormStore.addRow()`
6. AG Grid 渲染数据

**关键代码**：
```typescript
// hooks/useFileUpload.ts
const uploadMutation = useMutation({
  mutationFn: (file: File) => api.recognizeImage(file),
  onSuccess: (response) => {
    response.data.rows.forEach((row) => addRow(row))
  },
})
```

---

### 功能 2：语音输入与识别

**流程**：
1. 用户按住麦克风 → `VoiceInput.tsx`
2. RecordRTC 录制音频 → `useVoiceRecorder` Hook
3. 停止录音生成 Blob → `stopRecording()`
4. 上传到后端 → `api.recognizeAudio()`
5. 后端执行命令 → WebSocket 返回更新指令
6. 更新表格状态

**关键代码**：
```typescript
// hooks/useVoiceRecorder.ts
const recorder = new RecordRTC(stream, {
  type: 'audio',
  mimeType: 'audio/wav',
  // ...
})
```

---

### 功能 3：歧义处理（人机协作）

**流程**：
1. 后端检测到歧义 → WebSocket 发送 `tool_action: mark_ambiguous`
2. `useAgent` Hook 接收消息 → 调用 `setAmbiguous()`
3. 单元格变黄 → 渲染 `AmbiguousCell` 组件
4. 用户点击选择 → 弹出候选下拉框
5. 选择正确值 → `resolveAmbiguity()` 更新状态
6. 单元格恢复正常 + 置信度设为 1.0

**关键代码**：
```typescript
// hooks/useFormStore.ts
resolveAmbiguity: (rowIndex, key, selectedValue) => {
  // 更新单元格值，清除歧义标记
  newRows[rowIndex][cellIndex] = {
    ...cell,
    value: selectedValue,
    isAmbiguous: false,
    confidence: 1.0,
  }
}
```

---

### 功能 4：实时可视化

**流程**：
1. WebSocket 接收 `step_start` 消息 → 更新 `currentStep`
2. `ProcessGraph` 监听状态变化 → 高亮对应节点
3. 节点动画 + 连线动画 → Framer Motion / React Flow
4. 显示实时日志 → 底部日志区域

**关键代码**：
```typescript
// components/visualizer/ProcessGraph.tsx
useEffect(() => {
  setNodes((nds) =>
    nds.map((node) => {
      if (currentStep === 'ocr' && node.id === '1') {
        return { ...node, className: 'animate-pulse' }
      }
      return node
    })
  )
}, [currentStep])
```

## 📐 命名与编码规范

### 命名约定
- **文件名**：
  - 组件：`PascalCase.tsx` (e.g., `SmartTable.tsx`)
  - 工具函数：`camelCase.ts` (e.g., `helpers.ts`)
  - 类型定义：`camelCase.d.ts` (e.g., `schema.d.ts`)

- **变量命名**：
  - 前端：`camelCase` (e.g., `productName`)
  - 后端：`snake_case` (e.g., `product_name`)
  - 常量：`UPPER_SNAKE_CASE` (e.g., `API_BASE_URL`)

- **API 路径**：`kebab-case` (e.g., `/api/smart-form/submit`)

### 代码风格
- 使用 ESLint + Prettier 自动格式化
- 单引号字符串
- 无分号（Prettier 配置）
- 2 空格缩进
- 每行最大 100 字符

## 🔧 常见问题排查

### 问题 1：TypeScript 类型错误
**解决方案**：
```bash
npm run type-check
```
- 检查 `tsconfig.json` 的 `paths` 配置
- 确保导入路径使用别名（如 `@types`、`@hooks`）

### 问题 2：WebSocket 连接失败
**排查步骤**：
1. 检查后端 WebSocket 服务是否启动
2. 查看浏览器控制台错误
3. 验证 `.env.local` 中的 `VITE_WS_URL`
4. 检查 `services/websocket.ts` 的重连逻辑

### 问题 3：AG Grid 表格不显示
**可能原因**：
- 数据格式不匹配（检查 `FormRow` 类型）
- 缺少 AG Grid CSS（已在 `SmartTable.tsx` 中导入）
- 列定义错误（检查 `columnDefs`）

### 问题 4：样式不生效
**检查清单**：
- ✅ TailwindCSS 配置 (`tailwind.config.js`)
- ✅ 全局样式导入 (`main.tsx` 中导入 `globals.css`)
- ✅ PostCSS 配置 (`postcss.config.js`)
- ✅ 自定义类名是否在 `content` 扫描范围内
